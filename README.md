# 星际留白团队推文卡片工具

一个先本地运行的团队推文素材库与卡片制作网页。当前版本用于确认产品结构和制作体验，已经打通：

- 团队推文库浏览、搜索、按作者与分类筛选、选择并跳转 X 原贴
- 默认载入 rwayne 与黄小木的 122 条纯文字贴文；网页不提供贴文文件导入入口，素材由受控离线同步更新
- 推文来源与发布账号分离
- 仅显示当前用户可用的发布账号（原型内存权限）
- 发布账号只保留黄小木与 Roland.W，账号切换同步名称、ID、认证状态和名称标签
- 正文编辑、使用原推、10 张城市与风景背景（4 张既有素材与 6 张 3:4 精选图）、上传/网络图片
- 同步正文保留原始段落、空行、手动换行、连续空格、标点与链接；回复、转推、点赞、书签在源数据存在时同步
- 左侧素材候选卡直接显示浏览、回复、转推、点赞和书签数据
- 五项候选数据固定保持单行；选中素材时自动带入原始数据，也可在右侧逐项修改当前卡片数据
- 背景压暗、拖动位置，以及在卡片右下角直接等比缩放
- 内部卡片按现有 X 截图的固定字号与比例重做：省略号、常规字重正文、日期/浏览量，以及回复、转推、点赞、书签、分享五个矢量图标
- 制作器、卡片与导出 PNG 统一使用直角版式
- 海报不添加底部团队水印
- 发布文案生成、复制与 1080 × 1440 PNG 下载

## 本地运行

网页运行需要 Node.js 22+ 与 pnpm。重新生成默认素材时还需要 macOS 自带的 Swift / Vision，用于从 rwayne 的现有 X 截图读取四项互动数据。

```bash
pnpm install
pnpm dev
```

默认地址：`http://localhost:3000`

验证：

```bash
pnpm build
pnpm test
pnpm lint
pnpm data:sync
pnpm data:high-exposure
```

`pnpm data:sync` 会从相邻 `Social` 工作区中 rwayne、黄小木的两份 `collection_manifest.json` 重新生成脱敏后的默认素材数据，并且只读取 `pure_text_posts`。分类同时读取黄小木的分类清单、rwayne 已按分类整理的素材目录，以及项目内分类修订清单。AI 内容细分为 `AI工具`、`AI效率`、`AI实操`、`AI世界观`、`AI认知`、`AI商业`、`AI学习`；非 AI 内容保留原分类。网页只显示每条素材的实际分类，“纯文字”和“类别”都不作为界面类别或标签。输出只包含公开正文、来源、日期、链接、分类和公开指标，不复制 Cookie、凭据或源文件绝对路径。

项目级 Skill 位于 `.agents/skills/x-high-exposure-pure-text/`。它编排相邻 `gary-x-skills` 中的严格 X 原帖抓取与高曝光纯文字筛选，保留正文排版和五项公开数据。`pnpm data:high-exposure` 会把已经严格校验、筛选并完成语义分类的本地结果合并进默认素材；没有完成分类的候选会拒绝入库。

## 当前边界

网页本身不读取 Cookie、不直接连接 X、不自动发布，也不包含真实登录、数据库或服务端权限。当前页面只保留制作台和推文库，不提供团队设置页。项目级 Skill 只调用相邻工具仓库中已经授权的受控采集进程；Cookie / storage state 留在该进程的 Git 忽略目录，经过校验的公开素材才由离线脚本写入网页数据。
