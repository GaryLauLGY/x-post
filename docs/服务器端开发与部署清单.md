## 素材与 crawler 当前规则

- 只使用项目指定的 `gary-x-post-crawler`、项目登录态和项目运行时。
- 只导入严格验证为原创、纯文字、无回复/转帖/引用/媒体/URL，且曝光严格高于作者门槛的记录。
- 新严格候选直接写为 `approved` 并进入制作台。
- 已有人工分类、`rejected` 和 `archived` 状态不回退；现有素材只幂等更新公开互动指标。
- 任一作者覆盖不完整、搜索部分失败或发生资料页回退时，保留产物且不推进该作者水位线，不降低规则重试。
- 不自动发布、不发送消息。

## 数据与安全边界

- PostgreSQL、媒体、crawler 状态、导出和备份不进入 Git checkout 的源码目录或构建上下文。
- `.env` owner-only 且被 Git 忽略；不得输出值。
- `data/crawler/storage-states/` 目录权限 `700`、文件 `600`，不得复制到 Mac、其他项目、日志、文档或备份。
- 管理员使用现有本地 `admin`、PostgreSQL scrypt 哈希和可撤销服务端会话；无公开注册，密码只通过 bootstrap stdin 设置。
- 迁移和导入必须幂等；数据库 schema 变更前必须备份。
